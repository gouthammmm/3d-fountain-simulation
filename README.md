# 3D Fountain Simulation

A computer graphics project that simulates a flowing fountain using OpenGL and GLUT.

## Tools & Technologies

* C++
* OpenGL
* GLUT
* Code::Blocks

## Project Work

* Computer graphics programming
* OpenGL-based rendering
* Fountain and water-flow simulation
* 2D/3D graphical elements
* Animation and visual effects

## Project Files

* `main.cpp` — Main C++ source code
* `CG mini prjct.txt` — Project-related documentation
* `flowing fountain.cbp` — Code::Blocks project file
* `flowing fountain.depend` — Project dependency configuration
* `flowing fountain.layout` — Code::Blocks layout configuration

## Objective

The project demonstrates the use of C++ and OpenGL/GLUT to create an animated computer graphics simulation of a flowing fountain.
